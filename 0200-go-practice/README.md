# Go Practice

## 課題

1. 基本構文と型を使い、数値を集計するコンソールアプリを作成する。
2. 連結リストの追加・探索・削除を実装する。
3. Stack と Queue を実装し、LIFO・FIFO の動作を確認する。
4. 階乗と木構造の走査を再帰で実装する。
5. バブルソートとマージソートを実装する。
6. 各処理の計算量を整理し、入力件数による違いを説明する。

## 学ぶこと

1. Go Syntax：基本構文、基本型・複合型、関数、エラー処理
2. 構造体、メソッド、インターフェース、パッケージ
3. List / Stack / Queue：データ構造
4. Recursion：再帰と終了条件
5. Sort：ソートアルゴリズム
6. O(n)：計算量の考え方

## 完了条件

- 空入力、要素1件、重複値を含む入力でも期待どおり動作する。
- 各データ構造の用途、再帰の終了条件、計算量を説明できる。
