# HTML/CSS + Go

## 課題

- go でのかんたんな Todo アプリの作成
- Go から HTML/CSS を配信し、Todo の一覧・追加・完了・削除を実装する。
- CSS で未完了と完了の状態を区別する。
- データはメモリ上で管理してよい。

## 学ぶこと

- Web アプリケーションの基本的な構造
- HTTP リクエストとレスポンスの処理
- URL アクセスしてから HTML が表示されるまでの流れ
- HTML/CSS の基本

## 完了条件

- ブラウザーから Todo の一覧・追加・完了・削除を操作できる。
- Go、HTML、CSS の役割と HTTP の流れを説明できる。
