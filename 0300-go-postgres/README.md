# Go + Ent

## 課題

Go・PostgreSQL・Ent で、X のような短文投稿アプリのデータ層を作成する。

1. ユーザーと投稿のテーブル、主キー・外部キー・必須制約を設計する。
2. SQL で CRUD と JOIN によるユーザー別の投稿取得を行う。
3. Ent のスキーマとリレーションを定義し、コードを生成する。
4. Go から Ent で CRUD とユーザー別の投稿取得を実装する。
5. トランザクションを使い、失敗時のロールバックを確認する。

## 学ぶこと

1. リレーショナル・データベース
2. ORM (Ent)
3. テーブル定義
4. PostgreSQL / SQL：CRUD、JOIN、制約
5. トランザクションとデータの整合性

## 完了条件

- 再起動後も保存したユーザーと投稿を取得できる。
- 制約違反や存在しないデータへの操作を扱える。
- SQL と Ent の対応、テーブル間の関係を説明できる。
