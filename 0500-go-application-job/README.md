# Go ApplicationJob

## 学ぶこと

- HTTP リクエスト処理とバックグラウンドジョブの分離
- Email：メールの組み立てと送信
- CSV アップロード：ファイル受付、解析、入力検証、登録
- ジョブの状態管理、失敗時の再試行、重複実行への対処

## 課題

Go で予約システムを作成し、メール通知と CSV 取り込みをジョブとして実装する。

1. 予約の登録と一覧表示を実装する。
2. 予約登録後に確認メールを送信するジョブを実行する。
3. CSV をアップロードし、複数の予約を取り込むジョブを実装する。
4. 必須項目と日時形式を検証し、不正な行と理由を記録する。
5. 待機中・実行中・成功・失敗の状態と処理結果を表示する。
6. 再試行による予約やメールの重複を防ぐ仕組みを実装する。

メールの確認にはローカルのメール受信環境を利用する。

## 完了条件

- 予約登録後に確認メールを受信できる。
- 正常な CSV を取り込め、不正な行のエラーを確認できる。
- 失敗・再試行時の動作と重複を防ぐ仕組みを説明できる。
